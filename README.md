## 🧠 این برنامه چطور به وجود اومد؟

این برنامه از یه نیاز شخصی شروع شد:  
من یه دانشجوی کامپیوتر بودم که با **اهمال‌کاری، بی‌نظمی و حسِ عقب‌افتادن** دست‌وپنجه نرم می‌کردم.  
همه‌ی کتاب‌ها و روش‌ها رو امتحان کردم، ولی هیچ‌کدوم موندگار نبود.

تا اینکه تصمیم گرفتم **ابزار خودم رو بسازم**.

با کمک هوش مصنوعی، قدم‌به‌قدم این اپلیکیشن رو طراحی کردم، نه به‌عنوان یه پروژه‌ی دانشگاهی، بلکه به‌عنوان **یه هم‌نشین روزمره** برای خودم.

حالا بعد از کلی تلاش، این برنامه اینجاست تا به بقیه هم کمک کنه.

> **اگه تو هم حس می‌کنی زندگی‌ات نیاز به یه فرمانده داره، +lifeBOSPro همون فرمانده‌ست.**
